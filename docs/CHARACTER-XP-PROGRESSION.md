## Временные цели (модель, не гарантия скорости)

Без ускорителей опыта: будни 2 часа, суббота 4 часа, воскресенье без обязательной игры. Обычный моб: 5–10 секунд убийство + ~10 секунд переход; с паузами расчётно **140 убийств/час**. На обычных этапах гипотеза 85% XP за бой / 15% за квесты, будущая математика HP/сложности ещё не реализована.

Итог **258 часов 10 минут**, примерно **33 460 обычных мобов** (без профессиональных испытаний). Профессия I (20→24): **460 913 ЗРП**; профессия II (40→44): **9 550 092 ЗРП**; III (60→60,5): **120 154 918 ЗРП**; финальная 64→65 требует все **1,1 млрд** из разных источников. Пример для финала: 5 880 × 159 014 = **935 002 320**; оставшиеся **164 997 680** — квестовые ЗРП.

Три стартовых квеста могли бы давать +1 000/+2 000/+500 ЗРП, оставив на ЗРЛ 3 значение 500/4 076. Если начальный ОТВ=1, гипотеза +199/+200/+200 даст ОТВ 600. Прежние **шесть вступительных заданий по ~100 ОТВ** остаются в истории и могут быть шестью подзадачами трёх квестов. **Конкретный запуск этих наград не входит в патч.**
