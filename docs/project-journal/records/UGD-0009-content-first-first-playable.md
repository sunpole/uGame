# UGD-0009 — Сначала playable-контент, архитектура по необходимости

- Дата: 2026-10-02
- Статус: accepted
- Теги: gameplay, development-process, architecture, prototype, first-playable

## Контекст

После реализации базового фундамента — движения, зон, взаимодействий, квестов, сохранения и WorldGraph — стало видно, что дальнейшее последовательное строительство крупных универсальных систем слишком долго оставляет проект без ощущения самой игры.

## Принятое направление

Следующий этап uGame строится **content-first**:

- сначала делается маленький связный игровой кусок, который можно пройти;
- существующие системы используются максимально полно до строительства новых;
- новая архитектура добавляется только тогда, когда конкретный игровой сценарий показывает реальную необходимость;
- большие запланированные системы не отменяются, но перестают быть обязательной линейной очередью до появления playable-контента;
- каждые несколько версий желательно давать игроку заметное новое действие, цель, локацию, выбор или результат, а не только внутренний рефакторинг.

## Первый практический тест

`v0.0.31` становится первым небольшим playable-срезом без боя:

1. Проводник формулирует цель.
2. Игрок исследует четыре связанные зоны.
3. Находит три разных фрагмента.
4. Может выбрать маршрут и выполнять находки не строго по порядку.
5. В одной из зон есть необязательный тайник.
6. Финальная цель — активировать погасшее ядро.
7. Значимые действия сохраняются через уже существующий SaveSystem.

## Архитектурное следствие

`Interactable 2.0`, `TimeService`, `Quest/Dialogue 2.0` и другие крупные системы теперь не должны реализовываться целиком только потому, что находятся следующими в старом плане. Сначала определяется конкретная игровая потребность; затем добавляется минимальная часть системы, которая эту потребность закрывает, с сохранением возможности расширения позже.

Это не запрет на архитектурную работу. Фундаментальные изменения допустимы, когда без них сложно или опасно сделать следующий игровой кусок.

## Что не меняется

- бой и враги остаются отложенными;
- принятые решения UGD-0008 остаются в силе;
- Project Journal продолжает хранить гипотезы и будущие планы;
- сохранение и стабильные id мира остаются частью фундамента.
