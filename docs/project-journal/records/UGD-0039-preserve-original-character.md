# UGD-0039 — сохранить первого человечка uGame при внедрении спрайтов

Дата: 2026-10-12  
Тип: architecture / character visuals  
Статус: accepted  
Flags: needs-prototype, needs-test  
Теги: ui, character-build, npc, gameplay, technical

## Принято владельцем

**Первый игровой человечек uGame должен остаться доступным для использования** и после подключения сторонних или собственных спрайтов персонажей. Новые персонажи **дополняют**, а не заменяют исходного героя.

## Что имеется сейчас

- Оригинальная визуализация `src/character-view.js` строит фигуру непосредственно в Phaser (части тела, тень, поворот и движение), а не использует импортированный PNG spritesheet.
- На момент решения `main` и последний опубликованный релиз — `v0.2.74`, коммит `da1d4e7e51e15225dc982c6b2f16843c89b40e8c`.

## Требования к будущей Sprite Library (ещё не реализовано)

1. Сохранить исходный визуальный модуль и его текущие движения; не удалять и не перезаписывать ради новых ассетов.
2. Предоставить в будущей библиотеке **выбираемый вариант** оригинального персонажа (временная метка «Оригинальный uGame»). Можно использовать его как героя, NPC или моба, когда система выбора визуала будет реализована.
3. Подключать новые наборы параллельно; несовпадающие размеры и анимации адаптировать отдельно. Оригинальный вариант — естественный резервный fallback, если у спрайтов возникнут ошибки загрузки.
4. Планируемые виды экипировки: меч и щит, по мечу в каждой руке, книга, другие предметы. **Поддержка этих предметов исходным персонажем ещё не написана**; её нужно отдельно спроектировать без принудительного изменения существующего движения.
5. Сохранения, характеристики, XP, экипировочные бонусы, баланс и игровую концепцию не изменять только ради смены внешности.

## Статус и проверки

Это **зафиксированное проектное решение, не выпуск игрового патча**. Никакой новый переключатель, PNG-пакеты, анимации оружия или новое API в игре пока не созданы. При реализации понадобятся Node-тесты и настоящий Chromium desktop/mobile smoke-test на Phaser, Pre-flight, переключение вариантов, F5 и регрессию исходной модели.

Связано с UGD-0038 (развитие персонажа). Для использования внешних ассетов отдельно проверить лицензии и допустимость хранения файлов в публичном GitHub.
