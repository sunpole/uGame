# UGD-0037 — пять внешних колец мира

Дата: 2026-10-09  
Тип: architecture / world / npc-runtime  
Статус: accepted  
Flags: needs-test, needs-calculation, temporary-names  
Теги: world, world-map, locations, safe-city, distance, npc, rarity, tier, performance

## Принято владельцем проекта

Вместо 20 внешних зон вокруг пяти безопасных городов добавить **пять внешних колец локаций**. При сохранении логической квадратной сетки начальные 5×5 расширяются до **15×15 = 225 локаций**. Это означает 200 новых полевых зон: 220 внешних зон всего. В каждой внешней зоне сохраняются **12 возможных Event/NPC spots**, при этом число активных событий ограничено текущим Location Tier.

Главная цель: увеличить количество ресурсных мест-кандидатов и сделать достижимыми расстояния 3–10 переходов от городов, для которых уже существуют весовые таблицы LT.

## Инварианты

- 25 прежних ID и связей, 5 мирных городов и Перекрёсток сохраняются.
- Реальные ворота остаются NW/NE/SW/SE.
- 1 кандидатное место не равно 1 гарантированному NPC.
- Существующие правила реального времени, экспедиции и крафта не меняются.
- При LT T1 шанс Master T4 остаётся 1,5%: этот процент относится к отдельному выбору NPC.
- Мировые лимиты на ресурс T4≤1, T3≤2, T2≤3 остаются **максимумами, не гарантией наличия**.
- Новые биомы и названия временные до отдельного ЛОР-решения.

## Реализация QA-кандидата

Отдельный draft PR #13: https://github.com/sunpole/uGame/pull/13, версия v0.2.52. Все 225 зон связаны, расстояния D1–D10, 220×12 потенциальных мест. Для производительности индекс соседей и multi-source BFS строятся при загрузке графа. Карта прокручивается.
