# UGD-0040 — «Лесной вор»: первый PvE-моб

Дата: 2026-10-13
Тип: mechanic
Статус: accepted
Flags: needs-test, needs-calculation
Теги: combat, npc, gameplay, progression, world, character-build

## Что владелец попросил

Начать вводить настоящих мобов. Агрессивные мобы имеют индивидуальный радиус агрессии (пример 200 px); пассивные позволяют подходить вплотную и вступают в бой **только после удара по ним**. Социальные мобы при агрессии на одного зовут ближайших социальных мобов в собственном заданном радиусе. У каждого есть точка появления и радиус погони, после выхода из него моб должен перестать преследовать героя.

**Первый экземпляр — «Лесной вор», ЗРЛ 3:** passive, social=нет, socialRadius=нет, HP=330, HPS=5, RP/RPS=нет, бег 60, скорость атаки 80, шанс крита 4, сила крита 2, АТК 12, радиус атаки 10 px, агро 0, погоня 450 px, защита 12, уклонение 0, способности/стоимость/КД отсутствуют. Файл героя владелец предоставит сам: `uGame_real_knight_WALK_8x11_green.png`.

## Границы первого прототипа v0.2.78

- Выбрана тестовая лесная зона `loc-00009` (координаты `1060,960`) — **техническое размещение, не утверждённая карта спавнов**.
- Поведение в точности как запрошено: до удара пассивен, после удара преследует, срыв на 450 px от точки появления, возвращение и восстановление полного ХП. Последнее — прототипная гипотеза о сбросе схватки.
- Существующий радиальный «Импульс» наносит 50 урона, защита моба 12 даёт пробитие 38 за попадание — **временная простая формула**. Другие навыки не изменены.
- Скорость атаки 80 **временно** читается по словарю Character Lab как 0,8 удара/с. Крит 4 = 4%, сила 2 = ×2; урон моба применяется существующей функцией damagePlayer, без принятия формулы защиты игрока.
- За победу расчётный ЗРП = `floor(maxHP/10)` = 33, **гипотеза только для первого моба**, не принятая глобальная таблица XP. На ЗРЛ 65 начисление остаётся запрещено в существующей системе. Бонусы групп, разница ЗРЛ и штрафы — пока не связаны.
- Моб — клиентский прототип; при F5/повторном входе заново появляется. Нет серверного учёта убийств и защиты от фарминга через перезагрузку. Нет полноценной системы смерти игрока и дропа.
- Использует один из уже существующих 12 графических слотов `mob-human` (не добавлять новые роли). PNG импортируется владельцем через Project Hub, остаётся локальным и не затрагивает игровой save.
- Остальные Мастера и мирные NPC не становятся враждебными, баланс/сохранения/мировая карта не меняются.

## Что проверить

Сначала Node тесты поведения и настоящий Chromium desktop/mobile: Pre-flight, телепорт DEV 8590, пассивность вблизи, Импульс → агрессия → повреждение/погоня → выход из радиуса → возвращение, 33 ЗРП за победу, загрузка роли `mob-human`, F5. Только потом обсуждать регулярный респавн/антиабуз и настоящий бой.
