# Audit — v0.2.13 Master Reward Marker

1. Find a Master whose current Encounter reward has not been claimed.
2. A small red pulsing dot is visible above the NPC head while the NPC is inside Vision.
3. Walk with the wandering NPC: marker follows it.
4. Start Extraction: marker remains because the reward is not claimed yet.
5. Wait for Process completion: marker remains while reward is pending.
6. Successfully collect the resource: marker disappears immediately.
7. Interact again: Extraction is shown as "Добыча · получено" and disabled.
8. A second free Process cannot start in the same Encounter.
9. A new Encounter for that Master has its own new marker/reward.
10. Tier of the claimed resource matches the Master Tier.
