# uGame — собственные PNG для 13 ролей (v0.2.79)

## Самый простой сценарий для 2D-дизайнера
1. Запусти `Update-uGame.cmd` → **1 Update** → **11 Quick Run**, Pre-flight должен написать `v0.2.77`.
2. Открой **Project Hub → Игра → Атласы рыцаря · 13 ролей · DEV**.
3. Слева выбери роль — например, **Герой 1 · латный**. Меняй **масштаб и тень**, настройки сохраняются автоматически на данном устройстве.
4. Нажми **«Показать на моём герое»**, закрой Hub и походи: реальный рыцарь играет 8 направлений / 11 кадров шага.
5. Нажми **«Выбрать свой PNG с компьютера»**, выбери **полный исходный прозрачный лист 2816×2048**, дождись «PNG сохранён». Можно назначить разные PNG всем 13 ролям.
6. F5: при обычном Chrome изображение/масштаб восстанавливаются из IndexedDB/localStorage. Кнопка **«Вернуть стандартный рисунок»** убирает только локальный PNG данной роли. «Вернуть первого героя» возвращает исходный Phaser.

**Важно:** образец по адресу https://sunpole.github.io/uGame/labs/real-walk-atlas.html позволяет скачать настоящий **2816×2048** PNG. Загруженные через чат/мессенджер скриншоты часто имеют размер **2048×1489**, такие в игру импортировать нельзя: сетка уже изменена. ИИ-сгенерированный «похожий» лист со сдвигами кадров также пока не годится. В Photoshop сохраняй всю точную сетку, 8 строк направлений NW,N,NE,W,E,SW,S,SE и 11 кадров в строке, прозрачный фон PNG. Для каждого направления при ожидании с собственным PNG берётся его первый кадр ходьбы; у встроенного рыцаря есть отдельный кадр Idle.

## 12 назначений
- **4 героя** (латный, кожаный, тканевый, смешанный) — отдельные PNG и размеры. На своего героя применяются кнопкой просмотра; выбор сохраняется отдельно от игрового Save.
- **1 банкир** — во всех городах вместо старого процедурного тела, банкир остаётся обслуживающим NPC.
- **2 телепортера** — две цветовые/графические группы на существующих городских NPC; сервисы не меняются.
- **4 стража** — существующие гиды/стражи в четырёх специализированных городах используются как **визуальные заглушки для будущих правителей**. Новые персонажи-правители **не спавнятся**; Страж Каменного Перекрёстка использует отдельную нейтральную роль `guard-crossroads`; это пятое назначение городского стража, без нового NPC или изменения его диалога.
- **1 роль моба-человека** — графическая заготовка в библиотеке. Реального моба, боевого ИИ, урона и спавна **не добавлено**, потому что это отдельное игровое решение.

## Сохранность и ограничения
- Базовый набор CC0 автора Hormelz / Lower Lobby импортирован в GitHub как `data/knight-source/*.json` (walk 88 кадров + idle 136 кадров). Лицензия/источник https://github.com/kodareef5/lowerlobby/blob/44fcd8f8004e61c4d66da7b3c61db534c586e166/CREDITS.md.
- Игра строит **компактный временный Canvas atlas (128px ячейки)** из необходимых кадров. Исходные Photoshop PNG с 256px ячейками не записываются в игровой сейв и не загружаются на GitHub.
- Загрузка PNG — **только в конкретном браузере и домене** (`127.0.0.1` ≠ GitHub Pages; другое устройство не синхронизируется), IndexedDB может отсутствовать в приватном режиме. При блокировке исходный процедурный герой/старые NPC остаются fallback.
- Модель пока **цельная**, менять форму брони требует перерисовки нужных кадров. Только палитры у встроенного рыцаря меняются программно.
- Три поколения спрайтов (первый оригинал, старые 2D исследования, новый CC0) сохранены; логика взаимодействий, коллизии, FPS/скорость, баланс/XP, экономика, игровой Save v1 и данные мира не менялись.
