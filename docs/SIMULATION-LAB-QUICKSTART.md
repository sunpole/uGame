# Simulation Lab — быстрый запуск

Эта страница для первого запуска. Ничего устанавливать для web-варианта не нужно.

## Что такое GitHub Actions

GitHub Actions — это удалённый компьютер GitHub, который по нашей команде запускает Simulation Lab, считает тысячи или миллионы игровых циклов и складывает готовый отчёт в **Artifacts**.

Это не отдельная программа на твоём ПК и не часть самой игры.

## Почему на странице может не быть кнопки Run workflow

Если в правом верхнем углу GitHub видно **Sign in**, браузер сейчас не вошёл в твой GitHub-аккаунт.

Для ручного запуска workflow нужно:

1. Нажать **Sign in**.
2. Войти в аккаунт, у которого есть доступ к репозиторию `sunpole/uGame`.
3. Вернуться в **Actions → uGame Simulation Lab**.
4. Справа сверху появится кнопка **Run workflow**.

## Первый запуск — TEST 100 000

Для первого настоящего расчёта выбери:

- **mode:** `TEST`
- **cycles:** `0` — это означает использовать стандарт режима, то есть 100 000
- **world_size:** `8`
- **seed:** `42`

Затем нажми зелёную кнопку **Run workflow**.

Появится новая строка запуска. Пока он работает, будет жёлтый индикатор. После успешного завершения — зелёная галочка.

## Где результат

Открой завершённый запуск и прокрути страницу вниз до блока **Artifacts**.

Там будет ZIP примерно с таким именем:

`ugame-simulation-...-TEST-w8-s42`

Внутри главный файл:

`report.html`

Также там есть `summary.json`, CSV-таблицы и SVG-графики.

## Что означают режимы

- **TRACE** — 20 циклов. Нужен в основном разработчику для проверки логики.
- **TEST** — 100 000 циклов. Наш основной быстрый балансировочный прогон.
- **DEEP** — 1 000 000 циклов. Запускаем после TEST, когда хотим более устойчивую статистику.
- **MATRIX** — сравнивает одинаковые правила на мирах 8 / 30 / 50 / 100 зон.

Для первого раза выбирай **TEST / 8 зон / seed 42**.

## Локальный вариант

В `Update-uGame.cmd` есть пункт:

`9. Simulation Lab`

Это отдельный путь от GitHub Actions. Если Windows видит установленный Python, симуляция выполнится прямо на твоём ПК и откроет локальный HTML-отчёт.

Если Python недоступен из updater, он ничего не устанавливает сам и предлагает GitHub Actions.

[Открыть uGame Simulation Lab в GitHub Actions](https://github.com/sunpole/uGame/actions/workflows/simulation-lab.yml)
