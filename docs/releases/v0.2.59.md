# uGame v0.2.59 — понятные единицы баланса (Character Balance Lab)

**Статус:** QA-кандидат до выполнения CI, проверки Chromium и публикации v0.2.59.

## Что показывает лаборатория

Значения остаются сырыми баллами и отображаются первыми. Только рядом добавляется пояснение в тех единицах, которые прямо описаны в `docs/CHARACTER-BALANCE-LAB.md` и `data/character-stat-registry.json`:

| Показатель | Пример рядом с баллами | Основание / ограничение |
| --- | --- | --- |
| УКЛ (EVA) | `24 = 0,24%` | 100 баллов = 1% **кандидатного** уклонения; боевой шанс пока не реализован |
| ЗАЩ (DEF) | `150 = 1,5%` | 100 баллов = 1% **кандидатного** уменьшения урона; боевой модуль не реализован |
| ТОЧ (ACC), КРШ (CRIT CHANCE) | `250 = 2,5%` | 100 баллов = 1%; попадания и критические события пока не моделируются |
| УСТ (COST RED), УВМ (CDR) | `250 = 2,5%` | 100 баллов = 1%; пример 100 УВМ и базового КД 10 секунд → 9,9 секунды |
| УСУ (SKILL POWER), ГЛР (GLOBAL REGEN) | `250 = 2,5%` | 100 баллов = 1%; ГЛР относится к регенерации, а не к плоским очкам |
| СКА (ATK SPD) | `420 = 4,2 атак/с` | Только **условная черновая единица**. Базовая частота и анимации действующей игры НЕ утверждены |
| СКП (MOVE SPD) | `250 = 2,5 px/с` | Черновая единица 100=1 px/с; **не измеренное** перемещение Phaser |
| КРУ (CRIT DMG) | `120 = +120% к крит. урону` | 100 баллов = +100% дополнительного критического урона по исходному черновику |

ХП, РП, плоская АТК, вес, ячейки инвентаря и Шаги остаются без выдуманных процентов. Подсказки явно говорят, где эффект условный.

## Где отображается

- Таблица «Сравнение показателей»: `24 = 0,24%` в соответствующей ячейке.
- Закреплённые значения (📌) для 1–4 профилей: значение и его единица, подсказка и подробные источники.
- Формула выбранного показателя: исходные баллы и единица рядом, при этом trace остаётся неизменённым.

Все значения обновляются при изменении кандидатных коэффициентов, уровня и профиля. `src/character-balance/display-units.js` — чистая функция представления, НЕ игровое правило.

## Не менялось

- `src/character-balance/engine.js` и `data/character-balance-candidate.json`;
- 24 исходных числовых показателя, капы, округления расчётного ядра, API, модели;
- Snapshot JSON v1/v2, контрольная сумма, пользовательские английские ID, экспорт/импорт;
- GameState, SaveSystem, Phaser, шаги, бой и баланс настоящей игры.

**Статус UGD-0038 остаётся `discussing` / `candidate`, никаких скрытых принятых процентов.**

## QA

1. `npm test` — новые тесты единиц, точность `24 → 0,24%`, `420 → 4,2 атак/с`, 100 УВМ → 1%, маленькие дробные значения и неизменность рассчитанного snapshot.
2. `node tests/character-lab-browser-smoke.mjs` — реальный Chromium desktop/mobile: установить 24 УКЛ и 420 СКА, проверить таблицу, пин и trace, затем регресс профилей/редактора.
3. `node tests/character-lab-admin-browser-smoke.mjs` — старый Admin Lab: экспорт/импорт, SHA-256, валидация, sticky и мобильный scroll.
4. `node tests/browser-boot-smoke.mjs` — Pre-flight/Phaser/225 зон, world map и Save/F5.
5. Workflow `publish-v0259.yml` публикует QA prerelease **только после зеленого CI на main**. Ошибки до релиза блокируют merge.
