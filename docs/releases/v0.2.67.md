# uGame v0.2.67 — двуязычные DEV-команды, ЗРЛ/ЗРП/ОТВ и бесплатный телепорт в города

**Статус:** QA-кандидат. До merge в main и подтверждённого релиза **не считать опубликованным**.

## Запрос и границы

Владелец запросил DEV-систему для изменения опыта по **±5%, ±10%, ±50%**, прямого задания/повышения/понижения **ЗРЛ 1–65**, прямого назначения **ОТВ**, двуязычного справочника **всех существующих кодов**, а также бесплатный DEV-переход **из любой внешней/городской локации в любой из пяти мирных городов**.

Поскольку кривая «сколько ЗРП нужно до следующего ЗРЛ» ещё **не утверждена**, реализация строго трактует проценты как изменение **текущего сохранённого количества ЗРП**, не как «процент прогресса до следующего уровня». Например: 1000 ЗРП → +5% = 1050; −10% = 900. Для нуля проценты оставляют ноль; панель 2299 позволяет задать начальную величину. Нет автоматической смены ЗРЛ при достижении какого-либо порога и нет автоматической выдачи очков. Это только DEV.

## Новые коды

| Код | RU | EN |
|---|---|---|
| 2101 / 2102 / 2103 | +5% / +10% / +50% текущих ЗРП | Increase held ZRP by 5% / 10% / 50% |
| 2111 / 2112 / 2113 | −5% / −10% / −50% текущих ЗРП | Reduce held ZRP by 5% / 10% / 50% |
| 2201 / 2202 | ±1 ЗРЛ, диапазон 1–65 | ±1 maturity level, clamped to 1–65 |
| 2299 | DEV-панель: установить точные ЗРП, ЗРЛ, ОТВ (возможны отрицательные) | DEV panel: set exact XP, maturity level and signed responsibility |
| 2399 | Бесплатный выбор одного из 5 мирных городов | Free teleport picker for all 5 safe cities |

Все прежние активные коды сохранены и описаны двумя языками в `docs/DEV-CODES.md`, включая раньше пропущенные `1399`, `6401–6499`, `8661–8662`. Project Hub добавляет к строкам кнопку «Выполнить / Run». Неактивные диапазоны маркированы как reserved/резерв. Код `9999` по-прежнему открывает документацию.

## Архитектура и сохранение

- `src/dev-character-tools.js`: отдельная чистая арифметика DEV и контроллер кнопок/ввода. Никакого `eval`, произвольных системных команд или скрытых XP-порогов.
- `src/game-state.js`: сохраняются `player.characterProgress.zrl,zrp` (имеющаяся schema v1) и новое **необязательное** `player.characterResponsibility`. Старые сейвы получают только `null` (никакого автоматического 600 ОТВ). Прочие поля мира, Шагов, инвентаря, отношений, шахт и класса сохраняются.
- `src/character-draft.js`, `src/character-runtime.js`, `src/project-hub-system.js`: кандидатные расчёты 24 статов по тем же формулам Character Balance Lab для DEV-уровня и ОТВ. **Временное распределение дополнительных ВЫН/ЛОВ/ИНТ по правилам лабораторного `defaultProfile` — это симуляция**, не игровая выдача очков и не утверждение баланса.
- `src/main.js`: DEV route; `2399` проверяет все safe cities непосредственно в `WorldGraph`, затем вызывает штатный `ZoneSystem.travel({zoneId,entryId:'center'})` и обычное `zone:enter` сохранение, обновление видимости/звука. **Нет** вызовов платного `stepSystem.spendService`; стандартный городской телепортер не изменяется.
- `index.html`/CSS: адаптивная диалоговая панель, телефон/ПК, ввод точных чисел, шесть процентных кнопок, ±1 ЗРЛ, пять городов. Игровое управление временно блокируется, когда DEV-диалог открыт; закрытие возвращает управление при отсутствии других окон.
- Character Balance Lab / Character Admin Lab, их JSON v1/v2 экспорт/импорт, игровые таймеры, карта 225 зон, баланс, настоящие XP-награды и лимиты экономики не меняются.
- Project Journal `UGD-0038` остаётся **discussing**: числовой баланс прогрессии и эффектов ОТВ не утверждается патчем.
