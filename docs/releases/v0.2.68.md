# uGame v0.2.68 — настоящий RU/EN ввод всех DEV-кодов

**Статус:** QA-кандидат до merge в main, успешного CI и публикации GitHub prerelease.

## Причина

После выпуска v0.2.67 в репозитории уже работали:
- DEV **2101–2103 / 2111–2113**: +/−5%, 10%, 50% накопленных ЗРП;
- **2201/2202**: ЗРЛ ±1 до 1–65; **2299**: точное ЗРЛ/ЗРП/ОТВ (в том числе отрицательное ОТВ);
- **2399**: бесплатный выбор одного из пяти мирных городов без расхода Шагов;
- **9999**, Project Hub: двуязычный RU/EN справочник всех 67 действующих числовых DEV-команд.

Но нижняя DEV-консоль **принимала только 4 цифры**, поэтому просьба «поддержка ввода на русском и английском» оставалась выполненной не полностью.

## Исправление

- `src/dev-code-aliases.js`: **все 67 действующих кодов**, каждое документированное русское и английское название и небольшое число точных сокращений. Автоподбор выполняет **только известные целые названия** → прежний цифровой ID: `тп`/`tp`/`teleport` → `2399`, `зрп +5%`/`xp +5%` → `2101`, `уровень +1`/`level +1` → `2201`, `сохранить`/`save` → `9001`, `помощь`/`help` → `9999`.
- `src/dev-console.js`: вместо запрета букв — **двуязычный безопасный парсер** с Unicode минусами, регистром, ё/е, пробелами; без `eval`, без fuzzy-match или запуска произвольного текста. Все 4-значные старые коды по-прежнему работают, в т.ч. `9002` — удаление сохранения; похожая фраза не выполняет его.
- `index.html` и `src/style.css`: подсказки при вводе (`datalist`, **134 полных RU/EN названия**) и компактное адаптивное поле для Windows и mobile; Project Hub «Выполнить» без изменений.
- `docs/DEV-CODES.md`: обновлённая инструкция как вводить названия и цифровые коды. **Цифровые идентификаторы, баланс, формулы, XP-кривые, экономика телепорта, реальные сохранения, мир 225 зон и Character Lab/Admin Lab JSON не изменены.** Отдельно сохранён статус `discussing` для UGD-0038, поскольку числовой баланс не затронут.

## QA

- Новый Node `tests/dev-code-aliases.test.mjs`: все 67 кодов против актуального `docs/DEV-CODES.md`, RU/EN обе полные фразы, сокращения, регистр, минус, запрет опасных неточных команд и обратная совместимость четырёх цифр.
- Настоящий Chromium desktop/mobile: новая консоль принимает `тп` и `teleport`, открывает 5 городов; `персонаж` открывает панель ЗРЛ/ЗРП/ОТВ; `xp +5%` и `зрп -10%` работают; `save`/`сохранить` сохраняют; проверка подсказок, mobile-ширины поля, Pre-flight/Phaser, 225 зон, World Map, Save/F5, прежних цифр 2101/2399, Character Lab/Admin Lab JSON roundtrip.
- GitHub CI: Windows PowerShell Updater/texture publisher; Node suite; Chromium; GitHub Pages. **Ручная визуальная проверка на Windows владельца всё ещё нужна** — не выдавать CI за неё.

## Версии и откат

Перед патчем фактически подтверждён опубликованный неизменяемый **[v0.2.67](https://github.com/sunpole/uGame/releases/tag/v0.2.67)** = `580e636cfb60c8a445bf0de52b03fe3dd72f5d56`.

После релиза `v0.2.68`: `Update-uGame.cmd` → 1 Update → перезапуск → 11 Quick Run → DEV вводить `тп` или `tp`, `сохранить`/`save`, `зрп +5%` или `xp +5%`; `9999`/`помощь` открывает полный справочник. Рекомендуется **не проверять `9002` на важном сейве**. Возврат к предыдущим файлам через Updater 7 Rollback, затем 8 Return to main, без удаления localStorage.
