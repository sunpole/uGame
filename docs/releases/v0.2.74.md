# uGame v0.2.74 — опыт, повышение ЗРЛ и ручное распределение характеристик

**Статус при подготовке:** QA-кандидат до прохождения Node/Windows/Chromium, merge и GitHub prerelease. Не утверждать успешность заранее.

**Релиз ДО изменений (точка отката):** [v0.2.73](https://github.com/sunpole/uGame/releases/tag/v0.2.73), commit `e7d17e18915e5a15cfdce9beece1266b1c1f2bbd`. **После:** ожидается v0.2.74, только после PASS CI и merge.

## Изменения
- `src/character-progression.js` — проверка порогов XP и переходов вплоть до 65, перенос остатка в следующий ЗРЛ; после MAX новых ЗРП не хранить.
- `GameState.awardCharacterXp` — единая точка будущих боевых/квестовых выплат; на текущем этапе XP возможно задать через DEV 2299 или существующую команду ±%. Во время реального боя XP ещё не выдаётся: врагов пока нет.
- `player.characterAllocation` — опциональный безопасный журнал **потраченных** очков (ВЫН/ЛОВ/ИНТ). Бюджет: +3 обычный, +5 на 10/20/30, +10 на 40/50/55, +15 на 60, +20 на 65, на старте 10; к уровню65 248 дополнительно.
- UI «Характеристики»: свободные и потраченные очки, кнопки +1 к каждой характеристике и число пассивных очков. Лабораторный `defaultProfile` не используется для автоматического распределения игрового билда; HP/PP/RP/JP пересчитываются от игроком выбранных значений. Текущие запасы не лечатся автоматически при росте максимума.
- Схема `GameState v1`, класс/мир/сохранения/экономика/обновлятор и коэффициенты характеристик не меняются. Старые сейвы при чтении получают безопасное пустое распределение, не теряя другие поля.

## Как проверить владельцу на Windows
1. Updater 1 Update → 11 Quick Run, Pre-flight v0.2.74.
2. DEV 2299: ЗРЛ1, ЗРП2000 → должен получиться ЗРЛ2 и остаток ЗРП1000.
3. Открыть «Характеристики», свободно 3 очка; нажать **+1 ВЫН**. ХП максимум возрастёт, свободно 2, запись `characterAllocation.spent.vyn = 1`.
4. F5: сохранить очки, уровень и остаток. DEV ЗРЛ65 (без начисления ЗРП): пассивных очков 64 и общий максимум +248 для распределения.
5. Боевые/квестовые XP выплаты и дерево навыков пока отложены; целостность старого сейва и ручной Windows QA проверить отдельно.

**Отложено:** настоящий бой/XP-квесты, пассивные узлы и свободный стартовый узел города, квестовые бонусы очков, окончательные коэффициенты характеристик.
