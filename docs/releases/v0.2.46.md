# uGame v0.2.46 — рюкзак, банк, ресурсный сундук и организация вещей

Дата: 09.10.2026. Статус: **QA-кандидат**; ручной браузерный тест обязателен.

## Реализовано

- В интерфейс инвентаря добавлен **поиск** по русским названиям, Tier и ID; фильтр по категориям (ресурсы, экипировка, расходники, квестовые предметы и прочие), отдельный фильтр **T1–T8**, сортировка по названию, Tier, типу, весу или количеству.
- Кнопка **«Сортировать и собрать стопки»** объединяет одинаковые вещи в пределах размера стопки, сортирует и освобождает ячейки в *реальных* контейнерах, а не только визуально. Состояние автоматически сохраняется прежним `containers:changed`.
- Добавлен настоящий **Ресурсный сундук** (`resourceChest`, 48 ячеек, хранит только physical resources T1–T8). Доступен, как и банк, только в UI городского банкира; исходный банк остаётся отдельным 60-ячеечным хранилищем, а рюкзак — 12-ячеечным переносимым контейнером.
- **Перетаскивание мышью:** внутри рюкзака/банка/сундука по ячейкам (перестановка и объединение), на вкладку другого доступного хранилища (перенос с учётом заполненности, веса и типа). Всё проходит через `ContainerSystem`, с единым событием сохранения, без изменения предметов, если целевое хранилище не подходит. Для телефона/планшета сохранены явные кнопки переноса.
- **Удаление части или всей стопки:** кнопка «Удалить…» с указанием целого количества и вторым обязательным подтверждением `confirm`. Квестовые предметы дополнительно предупреждают о риске потери прогресса. Удаление необратимо; экипированный предмет сначала нужно снять.
- **Локализация** подписей действий и стопок, статистика слотов/веса и числа найденных предметов. Все существующие сейвы `GameState.schemaVersion=1` совместимы; новый сундук создаётся при загрузке, не заменяя старые.
- Крафт, экипировка, экспедиции и ограничения Tier из v0.2.45 сохраняются.

## Ограничения и проверка

- Перетаскивание здесь — браузерный HTML Drag & Drop для мыши. Сенсорное управление обеспечивают кнопки переноса; мобильный touch-drag пока не внедрён.
- Поиск/фильтры — локальные настройки интерфейса. Сортировка **действительно изменяет сохранённые позиции стопок**, поэтому важно заранее проверить привычные сценарии.
- Старые релизы для отката: [v0.2.45](https://github.com/sunpole/uGame/releases/tag/v0.2.45) и [v0.2.43](https://github.com/sunpole/uGame/releases/tag/v0.2.43).
- Следующий отдельный этап — **серверная авторитетная логика общих экспедиций для 12 участников**. Данный релиз не вводит действующий публичный мультиплеер.

### Автоматические регрессии

`npm test` и `tests/inventory-organizer.test.mjs`: поиск по русским именам/Tier, 48-ячеечный сундук, отказ неподходящим предметам, объединение без потерь, сортировка без изменения массы, перенос по ячейкам, лимит веса/типа, удаление и прежняя совместимость с экипировкой.

### Ручной Browser QA

1. Updater → 1 Update → 11 Quick Run, `ugame@0.2.46`, PRE-FLIGHT все зелёные.
2. Открыть рюкзак, найти «Камень», включить T1/T8 и фильтр «Ресурсы». Сбросить фильтры.
3. Скопить несколько стопок, нажать «Сортировать и собрать стопки»: количество кг/предметов не изменилось, освободившиеся ячейки появились.
4. Через городского банкира открыть «Банк», затем «Ресурсный сундук». Перенести Stone T1/T8 в сундук и обратно, попытаться перенести не-ресурс в сундук — безопасный отказ.
5. Перетащить стопку на пустую ячейку, на одинаковую стопку и на вкладку банка. Проверить сохранения после F5.
6. Нажать «Удалить…» на тестовом предмете, указать часть, отменить confirm, затем подтвердить удаление. Проверить точное списание и сохранение.
7. На сенсорном экране проверить кнопки переноса, вкладки и фильтры без drag. Экипировка, бесплатные награды NPC, мастерская и ресурсы экспедиции должны работать без изменений.
