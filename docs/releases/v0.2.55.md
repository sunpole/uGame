# uGame v0.2.55 — Character Balance Lab · DEV (QA prerelease)

Дата: 10.10.2026. Инструмент планирования, **не включён в боевой игровой runtime**.

## Что добавлено

- Project Hub → Инструменты → Character Balance Lab. Изолированная отдельная страница: сравнение 1–4 персонажей, по умолчанию ЗРЛ 1/10/40/65.
- 24 вычисляемых показателя: ХП/ХПС, ПП/ППС, РП/РПС, Желание/ЖПС, боевые характеристики, Шаги, вес и ячейки, ГЛР/УСТ/УВМ/УСУ. Каждая строка открывает цепочку всех исходных чисел, прибавок, процентов и верхних ограничений.
- Все независимые входы профиля, временные плоские добавки от будущих предметов/пассивов; интерактивный редактор кандидатных коэффициентов (не сохраняет).
- Четыре столицы, 21 допустимый стартовый набор, накопление очков 1–65, исключения контрольных уровней, ОТВ только полными сотнями, два взаимоисключающих режима Желания, ГЛР 100 единиц = +1% восстановления.
- Демонстрационный вход: 100 базовых ХП, 10 РП, ОТВ 1 до ЗРЛ 3 и ОТВ 600 с ЗРЛ 3. Эти числа, если не подтверждены отдельно, не становятся утверждённой системой.
- Отменённое допущение о нулевом итоговом Покрове на старте помечено устаревшим; +5 ПП уже на ЗРЛ 1.

## Без изменения

Игровые классы/ресурсы/профессии, баланс мастеров, XP, реальная скорость/регенерация, сохранения, карта, Phaser, экономики Шагов и Внимания не изменяются новым калькулятором. Модуль не импортируется игровым src/main.js. Редактор действует только в памяти отдельной вкладки.

## Проверка

- CI до публикации: npm test, Node-синтаксис, настоящий Chromium desktop 1365×768 и mobile 390×844 для новой лаборатории **и** существующего Pre-flight → Phaser → 225 локаций → DEV Analyzer → Save/F5.
- После merge проверить статус GitHub Actions; ручное Windows QA не заменяется CI.
- В игре: Updater → 1, перезапустить → 11; открыть Project Hub → Инструменты → Character Balance Lab.
- Изменить число профилей 1–4, уровни 1/10/40/65, ОТВ 600/699/700, ЖП>0/ЖП=0, +10 → +20 ХП/ВЫН, нажать строку ХПС/РПС/ГЛР и прочесть формулу. Сбросить. Затем проверить, что прогресс реального персонажа и SaveSystem прежние.
- Все неизвестные числа (бонусы стартовых пассивов, отрицательные модификаторы, базовая скорость атаки, группы) **не выдуманы**.
