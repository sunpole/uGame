# uGame v0.2.54 — реальный браузерный QA и восстановление запуска

Дата: 09.10.2026. **QA-предрелиз; пользовательская проверка на Windows остаётся обязательной.**

## Почему понадобился этот выпуск

v0.2.52 остановилась на устаревшем Pre-flight (25 зон вместо 225); v0.2.53 исправила размер мира, однако unit-тесты по-прежнему не проверяли настоящий браузер. Новый тест Chromium на чистом GitHub-клоне нашёл ещё две независимые проблемы:

1. Из 8 уникальных конфигурационных файлов биомных изображений в репозитории находятся только 2. Ранее Pre-flight блокировал запуск без оставшихся пользовательских текстур, хотя GroundTextureSystem уже умел скрывать отсутствующее изображение и использовать стандартный грунт.
2. Перед запуском невидимый игровой интерфейс расширял layout viewport мобильного браузера (390px device отображался как ~693 CSS px), из-за чего кнопка «Начать играть» могла перекрываться списком диагностики.

## Что исправлено

- Дополнительные биомные текстуры больше не являются обязательными для старта. Pre-flight проверяет уникальные изображения, пытается декодировать их и передаёт список реально доступных в Phaser. Отсутствующие/повреждённые дополнительные изображения безопасно пропускаются, а игра использует стандартный грунт.
- По-прежнему обязательны два базовых изображения, перечисленные в `data/preflight-manifest.json`, а также все JS, JSON и другие обязательные файлы.
- Невидимый до начала игры `#app` ограничен рамками viewport и больше не растягивает мобильную область просмотра; список диагностики прокручивается отдельно, кнопки прикреплены к низу стартового экрана.
- В режиме `CI` локальный dev-server не пытается запускать графический браузер сам.
- Архивный пункт документации старой карты 5×5 переименован с указанием, что он архивный.
- Новый `tests/browser-boot-smoke.mjs` проверяет **настоящий Chromium** на размерах 1365×768 и 390×844: HTML → Pre-flight → Phaser world ready → нажатие «Начать играть» → отображение canvas → Project Hub → карта 225 зон и 5 городов → «Показать меня» → DEV Analyzer → закрытие.
- Ошибки браузера и HTTP записываются, при неудаче GitHub Actions прикрепляет скриншот; тест запускается из чистого клона без пользовательских файлов и сохранений.
- Отдельный QA workflow автоматически проверяет каждый PR, затрагивающий игру или браузер. **Workflow публикации v0.2.54 повторяет браузерные и unit-тесты на main перед созданием релиза.**

Релизы `v0.2.53` (предыдущий QA-предрелиз), `v0.2.52` (с известным ошибочным Pre-flight) и `v0.2.51` остаются в GitHub Releases. Updater делает локальную резервную ссылку до обновления.

## Пользовательская проверка

1. Обновить локальную копию через `Update-uGame.cmd` → **1**, снова открыть Updater → **11**.
2. Проверить все строки Pre-flight, в том числе «225 зон · 5 городов · 840 переходов» и новую диагностику текстур. Отсутствие необязательных изображений не должно блокировать старт.
3. Нажать «Начать играть», открыть карту и DEV Analyzer. Проверить NPC, таймеры и Expedition вручную.
