# uGame v0.2.78 — первый лесной моб «Лесной вор» (QA-кандидат)

**Статус:** версия выпускается только после merge, успешного CI и публикации тега; фактический статус см. в [GitHub Releases](https://github.com/sunpole/uGame/releases/tag/v0.2.78) и [PR #93](https://github.com/sunpole/uGame/pull/93).

## Что изменено

- `data/mobs.json`: один LVL3 «Лесной вор» в `loc-00009` (1060,960), все значения автора: пассивный, нет социальности, HP330/HPS5, RP/RPS нет, бег60, СКА80, крит4%×2, АТК12/радиус10, агро0/погоня450, DEF12/EVA0, способностей нет.
- `src/mob-combat.js` — тестируемое поведение, от пассивности до погони/срыва/возврата, HP regen и крит.
- `src/mob-system.js` — настоящая Phaser сущность и HP bar на поле, без пересмотра Event Spots/Masters и спавна в безопасных городах.
- Настоящее попадание от уже существующего «Импульса» по enemy interface `receiveDamage()`. При первой победе через `GameState.awardCharacterXp()` получается 33 ЗРП по экспериментальной формуле maxHP/10.
- Визуал моба подключается к существующему слоту `mob-human`, где пользователь может загрузить `uGame_real_knight_WALK_8x11_green.png` в точном формате PNG 2816×2048. Без своего PNG есть встроенный CC0 спрайт.
- DEV команды `8590` — переход в лес на расстояние 45 px от моба; `8599` — контроль HP, состояния и расстояния до героя.

## Что остаётся вне патча

- Нет нового игрокового базового удара или изменений урона/стоимости «Импульса».
- **Открыто:** атакующий моб наносит базовые 12 урона по существующему HP без окончательной формулы защиты игрока; нападение заканчивается у радиуса 450 px от точки появления; при возвращении полностью восстанавливается. Это гипотезы для прототипа.
- Нормальный игрок пока может не иметь достаточно RP для быстрого убийства одним «Импульсом»; для проверки бойцовского цикла DEV `8673` отключает стоимость навыка, `8672` даёт тестовый минимум HP=1. Предстоящий basic attack и DPS баланс — отдельная задача.
- Нет полноценной смерти героя, лута, respawn cooldown, server authority и анти-F5. После F5 погибший моб вновь жив; XP за него можно получить повторно, поэтому не использовать прототип как окончательную экономику.
- Глобальную XP-кривую и результаты расчёта 258 часов не меняли; коэффициенты социальности, уровней, группы и коэффициенты сложности нуждаются в отдельном балансе.
- Не изменены существующий GameState/save schema v1, world.json, мастерские, Master NPC, экономика, 12 ролей, родной оригинальный герой.

## Тестирование

- `npm test` с новым `forest-thief.test.mjs`.
- Реальный Chromium desktop/mobile Pre-flight, Phaser, вход в `loc-00009`, 8599 idle → удар навыком → 8599 chase, победа +33 ЗРП и F5 smoke.
- Windows updater/texture tests. **Фактические PASS/FAIL проверить по GitHub Actions PR; ручной Windows QA владельца отдельно**.

## Как проверить

1. `Update-uGame.cmd` → `1 Update` → `11 Quick Run`; убедиться, что Pre-flight `v0.2.78`.
2. `Project Hub → Игра → Атласы рыцаря · 12 ролей · DEV` → роль «Человек-противник» → загрузить полный исходный `uGame_real_knight_WALK_8x11_green.png` (2816×2048), не скриншот.
3. В DEV поле написать `8590`, затем `8599`: герой появляется в 45 px от Лесного вора, в статусе отображается расстояние, моб спокоен до удара.
4. Подойти, применить навык клавишей `1`; после попадания начинается погоня. DEV `8599` показывает ХП и состояние. Если нужен QA скорости убийства, включить `8673`, `8672`.
5. Победить — XP HUD увеличивается на 33 ЗРП; UI остаётся на прежнем месте. После F5 — повторный спавн (известное ограничение).
