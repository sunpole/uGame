# uGame v0.2.63 — подписи городов внутри ромбов карты

**Назначение:** узкий визуальный патч поверх выпущенного v0.2.62. Карта стала чёткой при приближении, но длинные городские названия и метаданные выходили за границы ромбов. Пользователь просит сохранить качество, перенести текст и оставить возможность отката.

## Изменения
- `src/project-hub-system.js`: для городов вместо одной длинной строки `ГОРОД · специализация · биом` показаны две строки: `ГОРОД` и `специализация · биом`. Значения и подписи не теряются; поля по-прежнему показывают прежнюю единую строку.
- `src/style.css`: название города ограничено центральной шириной 76 px с аккуратными переносами (включая длинные названия «Беломраморный Двор», «Каменный Перекрёсток»). Строки ID, роли, биома компактны. Внутренний значок текущей локации закреплён отдельно, чтобы не растягивать блок текста по высоте.
- **Не изменены:** ромбическая геометрия, координаты и количество 225 зон, `src/world-map-camera.js`, CSS layout zoom v0.2.62, управление мышью/пальцем, внешний зелёный маяк, игровой баланс, сейвы, текстуры.

## Проверки
- `npm test`: регрессия включая отдельный тест разделённой городской подписи и сохранения подписей полевых зон.
- **Настоящий Chromium desktop/mobile**: все пять городов, 100%/175%/225% layout zoom, измерение реальных `getBoundingClientRect` четырёх текстовых строк относительно ромбической границы; city player marker, Pre-flight, Phaser, 225 zone map, pan/zoom/pinch, Save/F5, Character Lab.
- Windows PowerShell тесты Updater без изменения поведения.
- GitHub Actions релиза и Pages на объединённом `main`, отдельно от ручной оценки на Windows.

## Восстановление и откат
Независимая неизменяемая точка отката **[v0.2.62](https://github.com/sunpole/uGame/releases/tag/v0.2.62)** = `ae4694cbf3803e2a6c8f781e661d13aa213f0d33` подтверждена перед изменениями.

После публикации релиза v0.2.63: `Update-uGame.cmd` → `1 Update` → перезапуск → `11 Quick Run` → «Мир → Карта мира», проверить 100%, 175%, 225% и четыре названия специализаций/нейтральный город. Для отката использовать Updater пункт 7 (Rollback) и позже 8 (Return to main). Старые сохранения браузера не стирать.

**Ручной Windows QA владельца** — отдельно от GitHub CI, до него окончательная субъективная оценка читаемости не подтверждена.
