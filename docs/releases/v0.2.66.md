# uGame v0.2.66 — панель 7 навыков + первый радиальный импульс

**Статус:** QA-кандидат. Пока не merged и не опубликован — не называть выпущенным.

## Запрос пользователя и реализация

- **Семь слотов 1–7** — клавиатура, мышь и mobile touch запускают одну и ту же команду. Первый слот занят; остальные шесть пока явно «свободны».
- **Красный импульс**: при нажатии 1 у ног героя начинается красное кольцо (Phaser Graphics, не bitmap): радиус **1 px → 75 px** за **300 ms**, с плавным затуханием. КД **300 ms**, цена **35 ед. ЖП+РП**, фактическое списание **сначала Желание (ЖП), недостача — основной ресурс (РП)**. Если суммы недостаточно — навык отменяется, расхода нет. Успешный расход сохраняется сразу.
- **Урон 50** применяется к каждой отдельно зарегистрированной `isEnemy === true` цели с `receiveDamage` ровно один раз при достижении её расширяющейся волной (не при повторных кадрах). **Сейчас в Phaser нет реальных боевых NPC с HP** — мастера, торговцы, городской банкир и телепортер не становятся врагами и не получают урон. Тест unit проверяет две цели и исключение неприкосновенного NPC. Не утверждать, что текущий прототип уже позволяет убивать мобов.
- Реализована **регенерация ХП/ПП/РП/ЖП** по `hps/pps/rps/jps` исходного *кандидатного* `data/character-balance-candidate.json`, через общий движок `characterDraftResult`. Текущие значения сохранены в прежнем `player.characterPools`; при регенерации не превышают `max`. **ЖП начинает восстановление лишь после 3 непрерывных секунд с полным РП**, прекращает при падении РП ниже 100%; расход ЖП при полном РП не сбрасывает таймер. Сессионное wall-clock время из памяти JavaScript, а не SaveSystem timestamp: AFK/фон при открытом браузере учитываются, **закрытая игра не даёт регенерации**, после F5 офлайн-пауза не компенсируется.
- Для быстрой проверки всех четырёх бассейнов добавлены DEV **8661** (снять немного ХП, ПП, РП и ЖП без боёв) и **8662** (восстановить до рассчитанного максимума). Это диагностика, не обычная игровая механика; Stamina отдельно зелёной полосой, не менялась.
- Процент снижения стоимости УСТ / перезарядка УВМ **пока не подключены к импульсу**, потому что явные параметры 35/300ms пользователь просил как фиксированный тест. Баланс прочих механик, WorldGraph 225, реальные Master/Encounter timers, Stamina, экономика Шагов, ЗРЛ/ЗРП не изменены.
- Character Balance Lab и Admin Lab экспорт/импорт JSON не менялись; окончательный баланс всё ещё `UGD-0038: discussing`.

## Затронутые файлы

`src/character-skills.js` — чистые `spendImpulse`, `regenerateVitals`, `pulseRadius`, `applyPulseHits`, плюс контроллер ввода/ресурсного таймера. `src/main.js` — Phaser Graphics анимация, подключение контроллера, фоновая регенерация открытой вкладки. `index.html` и `src/style.css` — панель семи слотов. Тесты `tests/character-skills.test.mjs`, расширен реальный Chromium `tests/browser-boot-smoke.mjs`. Обновлены `version.json`, `package.json`, Pre-flight manifest, RELEASE / Project Journal.
