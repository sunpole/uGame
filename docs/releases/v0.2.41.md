# uGame v0.2.41 — Master indicators + first crafting loop (QA)

## Changed
- Existing 60-second Master Process remains real-time and unchanged.
- Marker lifecycle: unclaimed idle red; running red with mm:ss above; pending current Encounter green; claimed no marker/countdown.
- Marker state restored from CharacterMasterRelationships on zone relayout, revisit and game reload; no duplicated Phaser markers/tweens.
- Available everywhere in prototype: **Мастерская** button in lower desktop/touch controls.
- Live single T1 recipe: **камень 0,4 кг + дерево 0,2 кг → простой полевой инструмент ×1**.
- Atomic carried ContainerSystem deduction/output; failed output placement restores both inputs, completed craft sends one save event.
- No professions/city locks, dynamic balance adjustments, ore, hides or multiplayer server in this release.
