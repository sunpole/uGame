# uGame v0.2.75 — примерочная персонажей, первый процедурный герой сохранён

**Статус на этапе разработки:** QA-кандидат до PR merge, CI и публикации GitHub Release. Не указывать успешность тестов до фактического результата.

**Релиз до патча (точка отката):** [v0.2.74](https://github.com/sunpole/uGame/releases/tag/v0.2.74), commit `da1d4e7e51e15225dc982c6b2f16843c89b40e8c`. После проверок ожидается v0.2.75.

## Что изменено
1. `src/character-sprite-gallery.js` — пять **новых оригинальных рисунков** персонажей с 16 кадрами направленной ходьбы (4×4) на canvas. CC0-паки третьих лиц **не импортировались**.
2. `src/character-view.js` — не удалена ни одна оригинальная часть первого героя. Новые Phaser-картинки включаются временно и заменяют только визуал; оригинал — fallback.
3. `data/project-hub.json`, `src/project-hub-system.js`, `src/style.css` — отдельная примерочная с движущимися карточками, переключателем и возвратом в мир.
4. Выбор **не пишется в GameState**, не меняет показатели, движение, XP и сейвы, сбрасывается после F5. Оружие и слои экипировки в этом патче отсутствуют.
5. `tests/character-sprite-gallery.test.mjs` и `tests/browser-boot-smoke.mjs` — проверки atlas, 4 направлений, переключения с оригинала и обратно, F5, реального Phaser на desktop/mobile.

## План QA
Проверить `npm test`, Windows PowerShell regression, реальный Chromium desktop/mobile (Pre-flight, первый запуск, ходьба, смена 5 моделей, переключение обратно, F5). Эти проверки не заменяют ручную проверку на ПК владельца.

## Как проверить владельцу
Updater → 1 Update → 11 Quick Run → Примерочная персонажей · DEV (в Project Hub, раздел Игра), выбрать модель → выйти → походить → повторить. Оригинальный uGame — первый вариант, после F5 возвращается.

**Не завершено:** художественный выбор из вариантов, внешние лицензированные наборы, индивидуальные анимации предметов, отдельные боевые анимации, реальное пользовательское Windows QA. Утверждённый баланс не менялся.
