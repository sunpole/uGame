В предыдущем потоке PC→GitHub я ошибочно сохранял изображения под старые технические имена с размерами 256/512, хотя художник дал оригиналы 1024×1024 и потребовал сохранить **точные имена**:

| Назначение | Окончательный файл | Фактическое разрешение | Размер |
| --- | --- | --- | --- |
| Южная земля | `assets/textures/biomes/ground_1024.jpg` | 1024×1024 | 1 566 795 байт |
| Южный город (белый мрамор) | `assets/textures/biomes/city_ground_1024.jpg` | 1024×1024 | 619 299 байт |

**JPEG-байты взяты без перекодирования из уже загруженного пользователем PR #67.** Git blob SHA: земля `3104ad3bc4e1b226f3126411d23bd126444594ce`, город `04e2ca4b0f4b8d2f2cc352e5c8adb078c9cb2b23`. Старые неверные файлы `south_256.jpg` и `city_south_512.jpg` удалены (не поддерживаются как новые имена).

Изменены точные ссылки в `data/biome-textures.json`, загрузчике `src/ground-texture-system.js`, `data/preflight-manifest.json` и документации. Пункт **12** Updater берёт и публикует только `ground_1024.jpg` и `city_ground_1024.jpg` под **теми же именами** и проверяет реальное разрешение не ниже 1024×1024. Больше никаких скрытых переименований.

Пользовательские настройки Biome Visual Lab, сохранённые со старыми путями, корректируются **только при чтении конфигурации**, без удаления сохранений и без сброса параметров масштаба/прозрачности.

## Windows: обновление при прежнем «Local changes or untracked files exist»

Текстуры ранее были добавлены вручную на ПК, поэтому старый Updater правильно отказывается от обновления. До любых действий сохранить независимые оригиналы на рабочем столе. Затем из **CMD** (двойные кавычки, не одинарные!) выполнить `git -C "C:\!CODE_CLUB\new 2026\011_uGame" stash push -u -m "uGame assets before v0.2.61"`, чтобы безопасно сохранить все локальные изменения в Git stash. **Не применять stash целиком после обновления**: там старые удаления и пользовательские копии, которые могут конфликтовать с новой структурой. Затем открыть `Update-uGame.cmd` → пункт 1, перезапустить → 11. Правильные JPEG будут уже в отслеживаемых файлах.

Не удалять stash до восстановления любых других нужных локальных материалов. После обновления можно выборочно вернуть непрограммные `assets/UGAME.jpg` и `assets/UGAME_MAP_.jpg`; они не публикуются автоматически.

Ручная проверка Windows владельцем, включая картинку в южной столице, **остаётся отдельно от CI**.
