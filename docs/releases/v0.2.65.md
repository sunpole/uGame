# uGame v0.2.65 — игровые ресурсы персонажа: шары ХП/РП и слои ПП/ЖП

**Статус:** QA-кандидат до merge в `main`, успешных Node/Windows/Chromium CI и публикации prerelease.

## Подтверждено владельцем

- Красный шар **ХП (здоровье)**, синий **РП (основной ресурс)**.
- **ПП (Покров)** — отдельная защитная область *поверх* ХП; отображается золотой кольцевой дугой и собственным числом «ПП n/max».
- **ЖП (Желание)** — отдельная область *поверх* РП; отображается фиолетовой дугой «ЖП n/max».
- Зелёную **Stamina** оставить самостоятельной полосой и вписать визуально в эту композицию.
- Показать **ЗРЛ** (уровень зрелости до 65), **ЗРП** (текущее количество очков зрелости), полноценную панель всех характеристик.
- Character Balance Lab и Character Admin Lab сохраняются вместе со своим экспортом/импортом JSON; баланс корректируется позже по переданному пользователем файлу.

## Реализация

- `index.html` / `src/style.css`: уникальные компактные CSS-шары со стеклянным бликом, наполнением по фактическому отношению current/max, цветные кольцевые дуги поверх, текстовые подписи и tooltip. **Никаких чужих ассетов из Diablo, PoE, Lineage или Albion.** Адаптивная разметка в существующей шапке, не поверх Phaser-сцены.
- `src/character-runtime.js`: чистые `normalizeCharacterProgress`, `normalizeCharacterPools`, `currentCharacterVitals`, `poolRatio` + контроллер HUD. Единая формула `characterDraftResult` из Character Balance Lab, **без второй арифметики характеристик**.
- `src/game-state.js`: добавлены необязательные `player.characterProgress={schemaVersion:1,zrl:1,zrp:0}`, `player.characterPools={schemaVersion:1,profileKey,current:{hp,pp,rp,jp}}`. GameState **остаётся schemaVersion 1**, неизвестные/опасные поля отвергаются, старые сейвы сохраняют прежний класс/мир/контейнеры/мастеров/ресурсы. Для старого сейва без явного сохранённого Character Draft — ЗРЛ 1/ЗРП 0 и **пустые, не выдуманные шары** до выбора профиля. Для сохранённого профиля инициализируются текущие ХП/ПП/РП/ЖП расчётными максимумами лаборатории, затем текущие значения сохраняются с ограничением максимумом. При изменении профиля пересчитываются запасы.
- `src/main.js` связывает модель HUD и игровой Phaser GameState, а экран характеристик `src/project-hub-system.js` показывает ЗРЛ/ЗРП, current/max для четырёх ресурсов и остальные 24 показателя.
- Нет скрытого эффекта на бой, XP, рывки, Stamina, Шаги, расход умения, регенерацию, PvP, инвентарь. В проектном журнале UGD-0038 прогрессия ЗРП отложена до появления боёв/квестов. **Нельзя придумывать порог до следующего ЗРЛ**, поэтому выводится «ЗРП 0 · порог позже», без ложного прогресс-бара или фиктивного XP в игре.
- Числовые максимумы пока **кандидатные из Character Balance Lab**, `UGD-0038` остаётся `discussing`; реальный боевой расход и восстановление запланированы следующими согласованными патчами. Текущие значения теперь живут в настоящем игровом сохранении, но ещё не меняются боевыми событиями.

## Откат

До изменений подтверждён опубликованный неизменяемый **[v0.2.64](https://github.com/sunpole/uGame/releases/tag/v0.2.64)** = `408aa31ab997895858074c2cc2b06f370c94d13d`.

После релиза: `Update-uGame.cmd` → 1 Update → заново запустить Updater → 11 Quick Run → игра. На старом сейве сначала открой «Характеристики ↗», выбери и сохрани пробный профиль: красный и синий шары заполнятся, кольца покажут отдельные запасы. Проверь ЗРЛ/ЗРП и зелёную Stamina, F5 и статус сохранений. Кнопка 7 позволяет откат к предыдущему коду, 8 — возврат в main; не удалять browser localStorage и не применять случайный git stash.
