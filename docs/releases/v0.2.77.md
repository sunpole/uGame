# uGame v0.2.77 — 8 направлений, 12 графических ролей и Photoshop PNG импорт

**Статус документа:** QA-кандидат, релиз только после CI Node, Windows, Chromium desktop/mobile PASS на main.

## Изменено
1. Данные настоящих исходных CC0 sprite frames Hormelz / Lower Lobby (4 локальных JSON: manifest, palette, Walk 8×11, Idle 8×17). Визуальные кадры теперь в собственном репозитории, загрузка не зависит от стороннего CDN.
2. `src/knight-atlas-core.js`, `src/knight-role-library.js`: компоновка компактных Canvas/Phaser атласов из 8 направлений, локальные 12 ролей, импорт Photoshop PNG `2816×2048` с прозрачностью, IndexedDB для PNG и localStorage для настроек. Недопустимые размеры и непрозрачные скриншоты отклоняются.
3. `src/character-view.js`, `src/interactable-system.js`: герой ходит с новой графикой, NPC банка, телепортов и четырёх столичных стражей имеют визуальные версии без изменения интеракций. Первый процедурный герой остаётся резервным. Визуал моба заготовлен, но combat/spawn не добавлены.
4. `src/project-hub-system.js`, `src/style.css`, `data/project-hub.json`: понятный дизайнеру экран управления 12 ролями: выбор, PNG с ПК, масштаб, тень, сброс и применение к герою. Legacy-галерея не удалена.

## Вне задачи и ограничения
- Нет новых монстров, правителей как сущностей, боевых алгоритмов или выпадения опыта; существующие городские гиды используются как временный визуальный ориентир.
- Загрузка файлов локальная и не публикует их в GitHub; на другом устройстве нужен отдельный импорт. GameState и SaveSystem v1 не менялись.
- Формат для пользовательского PNG — единый прозрачный `2816×2048` лист 8 рядов по 11 кадров, **не** уменьшенный скриншот.
- Прежний опубликованный prerelease [v0.2.76](https://github.com/sunpole/uGame/releases/tag/v0.2.76) сохранён для отката (SHA `8645b6ed4930a05a02079ce94c7ac0d86e8875b3`).

## Тесты и инструкция
До окончания CI: **тесты ожидаются**. Реальные результаты проверяются в GitHub Actions. Windows ручной QA владельца после обновления остаётся отдельным.

`Update-uGame.cmd` → `1 Update` → `11 Quick Run`, потом `Project Hub → Игра → Атласы рыцаря · 12 ролей · DEV`. Подробно: [docs/KNIGHT-ROLE-ATLAS.md](../KNIGHT-ROLE-ATLAS.md).
