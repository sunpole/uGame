# uGame v0.2.64 — Character stats, этап 1: отображение + черновик

**Статус:** QA-кандидат до merge, успешного CI main и публикации prerelease.

## Цель и явные ограничения

Владелец выбрал постепенное внедрение характеристик: сперва **экран и сохранение черновика**, позже — отдельные решения об эффектах. Все коэффициенты `data/character-balance-candidate.json` имеют статус `discussing` в [UGD-0038](../project-journal/records/UGD-0038-anton-character-stats-draft.md). Эти числа не становятся игровым балансом.

- Project Hub → **Игра → Характеристики персонажа**, либо кнопка «Характеристики ↗» в шапке.
- Отображаются все **24 показателя** с расчётными единицами; используются `src/character-balance/engine.js` + `src/character-balance/display-units.js` — **нет второй формулы**.
- Можно выбрать одну из четырёх **пробных** моделей столиц и одно из 21 допустимых стартовых распределений 10 очков ВЫН/ЛОВ/ИНТ; ЗРЛ 1, ОТВ 1, ЖП>0 — отмеченные допущения лабораторного сценария.
- Пока пользователь не нажал «Сохранить черновик», игровое сохранение не содержит выбранного происхождения. После подтверждения хранится только `player.characterDraft: {schemaVersion:1,cityId,startIndex}`, без изменения `schemaVersion=1`; старые сохранения с `classId`, местом, предметами, NPC, XP профессий и ресурсами совместимы.
- Есть кнопка «Убрать черновик». Незнакомые/невалидные поля не принимаются; `otv`, `extraFlat` и лабораторные коэффициенты **не могут быть внедрены в GameState**.
- **Не активировано:** основной ресурс, расход/восстановление ХП/РП/ПП/ЖП, уровни/XP, бой, пассивы, скорость движения/атаки, влияние на Шаги/инвентарь, реальные города происхождения. Действующий класс Wanderer/Scout и Stamina остаются как были.
- **Character Balance Lab + Character Admin Lab + JSON v1/v2** экспорт/импорт/хеши оставлены без изменений. Отправленный владельцем позже JSON — материал для проверки и следующего PR, не источник автоматической замены gameplay.
- UGD-0038 остаётся `discussing`; эта работа — UI/сохранение технического прототипа, не новая механика.

- Chromium desktop/mobile: Pre-flight, запуск Phaser, открытие нового экрана из шапки, все 24 показателя, отсутствие черновика до нажатия, сохранение выбранного профиля, корректный `localStorage ugame.save.v1` и восстановление после F5; дополнительно 225 зон карты, Character Lab, Admin Lab и export/import regressions.
- Windows PowerShell updater QA; GitHub Pages / Actions на merged main отдельно.

## Установка и точка отката

Исходный стабильный prerelease **[v0.2.63](https://github.com/sunpole/uGame/releases/tag/v0.2.63)** = `66fd219c4f541f200839e3ed663fbe7ea4d844af`, опубликован и сохранён до патча.

После выпуска v0.2.64: `Update-uGame.cmd` → 1 Update → перезапуск → 11 Quick Run → кнопка «Характеристики» (или меню Игра). Выбрать пробный профиль, нажать «Сохранить черновик», затем DEV 9001 и F5. Проверить сохранение профиля, не сбрасывая настоящий класс/локацию/ресурсы. Для отката Updater 7, затем 8 Return to main; **не очищать браузерные сохранения**.
