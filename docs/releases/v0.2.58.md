# uGame v0.2.58 — world map viewport / map navigation

Status: QA candidate. Publish only after green Node + real Chromium desktop/mobile + Pre-flight/Phaser/Save/F5 on merged main.

## What changed
- Replaced the giant dual-scrollbar 225-zone world map panel with a bounded interactive viewport. World coordinates/diamond geometry are unchanged.
- Mouse wheel zooms toward pointer; click-drag pans. Mouse zoom +/- and keyboard + / - / arrows / Home / 0 are alternative controls.
- Touch drag pans; two-finger pinch zooms. Touch is captured only inside the map, not the rest of the game.
- «Показать меня на карте» finds the real current zone and returns a medium (92%) camera scale. The green «ВЫ ЗДЕСЬ» marker is still anchored to the current location even when another zone is selected.
- «Весь мир» fits all 225 zones into the viewport. Scale is bounded (fit×0.75 ... 225%) and pan is clamped; camera location is UI-only and never saved.
- Camera state survives a zone selection redraw while Hub map remains open, and resize preserves focus.

## Manual Windows acceptance (owner, after Updater → 1)
Open Project Hub → Игра → Карта мира.
1. Scroll wheel over a zone: that zone remains under mouse pointer as scale changes. Drag left/right/up/down; no two inner scrollbars.
2. Click «Весь мир»: entire 15×15 diamond becomes visible; click «Показать меня на карте»: green marker becomes central, readable zoom.
3. Select a neighboring zone, zoom/pan, use Find Me: selected is reset to current location, viewport refocused.
4. Confirm Escape/Close leaves normal game unchanged and F5 restores game save; map view preference itself need not persist.
5. Mobile: one finger moves map, two fingers zoom; page navigation outside map remains usable.
