# uGame v0.2.69 — управляемые DEV-аномалии персонажа

**Статус:** QA-кандидат до успешного CI, merge в main и публикации prerelease. Ручной Windows QA отдельно.

## Реализация

- `8671` / `без кд` / `no cd` — убрать только перезарядку навыков. Повторно — выключить.
- `8672` / `бессмертие` / `immortal` — ХП никогда ниже 1 в едином DEV damage helper `applyPlayerDamage` и runtime-страховке на tick. Повторно — выключить. Сейчас в мире **нет врагов, наносящих игроку урон**, поэтому будущий источник боевого урона должен вызывать этот helper и пройти отдельный PvE QA.
- `8673` / `бесплатные навыки` / `free casts` — тестовый навык не расходует ЖП/РП, даже если их недостаточно; перезарядка без `8671` остаётся обычной. Повторно — выключить.
- `8674` / `восстановить все` / `full refill` — одноразовое восстановление ХП, ПП, РП, ЖП до актуального максимума + Stamina. Не тратит/не выдаёт Шаги или Внимание. Не создаёт постоянного бафа; прежний `8662` (четыре запаса) не изменён.
- Рядом с блоком **ПЕРСОНАЖ** показываются три компактные иконки в духе RPG-бафов. У каждой кнопка `×` снимает ровно свой режим. Иконки сразу исчезают при повторном коде. На mobile — адаптивная строка.
- **Session-only:** после F5 три режима возвращаются в OFF; в GameState v1/localStorage они не сериализуются. Восстановленные ресурсы сохраняются обычным путём. Нормальная цена импульса (35 ЖП→РП) и КД 300 мс остаются при выключенных аномалиях. WorldGraph 225, Master, XP-кривая и candidate Character Lab не меняются.

## Проверки

- `npm test`: тесты переключения, сохранения состояний только в памяти, обычного КД, нулевой цены и двух подряд применений, границы ХП=1, безопасного нулевого ХП при OFF, 100% пополнения + вызова refill Stamina; обратная совместимость 67 прежних цифровых кодов, теперь 71 названий RU/EN.
- **Real Chromium desktop/mobile**: Pre-flight, Phaser, старая панель 7 скиллов, RU/EN DEV-ввод, реальный no-CD + free-cast, бафы и `×`, `8674`, Save/F5, World Map 225, Character/Admin Labs + JSON.
- Windows PowerShell Updater и сохранение бинарных текстур проверяются отдельным job в GitHub Actions.

**Внимание:** результаты пунктов выше нужно подтвердить по фактическому CI и Chromium, прежде чем выпускать релиз. Windows user QA не равен автоматическому Windows workflow. Проверка реальной неуязвимости против будущих монстров отсутствует, поскольку они ещё не существуют.

## Версия, проверка и откат

Предыдущий immutable [v0.2.68](https://github.com/sunpole/uGame/releases/tag/v0.2.68) — commit `ff094ba5f444b9e36eb58bfe134fd4d20f9821eb`.

После публикации v0.2.69: `Update-uGame.cmd` → `1 Update` → перезапуск → `11 Quick Run`. В DEV ввести `8671`, `8673`, несколько раз нажать `1` и проверить, что ЖП/РП не тратятся и КД не появляется. Ввести `8671` ещё раз и снять вторую иконку кнопкой `×`; затем `8674`, сверить ХП/ПП/РП/ЖП и Stamina. Проверить F5: DEV-бафов нет. `8672` включает значок бессмертия, но полноценное PvE-тестирование только после появления врагов.

Для отката файлов — Updater `7 Rollback`, затем `8 Return`; не удалять localStorage.
