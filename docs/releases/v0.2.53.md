# uGame v0.2.53 — исправление стартовой проверки WorldGraph

Дата: 09.10.2026. **QA-предрелиз для браузерной проверки.**

## Симптом пользователя

Браузерная диагностика v0.2.52 показывала:
`[FAIL] Целостность WorldGraph — WorldGraph zones must be 25 unique`.
При этом остальные базовые проверки, включая JSON, модули, версии и Phaser, проходили.

## Первопричина

`src/preflight-system.js:validateWorld` продолжал требовать устаревшую модель мира `25 zones / 5 cities / 20 fields / 80 transitions`, несмотря на добавление пяти внешних колец в v0.2.52.

## Исправление

- Число зон и переходов определяется из описания квадратной сетки `world.topology`, с обязательным минимумом 15×15 для новой сборки.
- Реальная карта 15×15 должна иметь 225 уникальных зон, 5 городов, 220 полей и 840 направленных переходов.
- Предусмотрены проверки на повторы ID переходов, неизвестные зоны в переходах, диагональные стороны и противоположные входы.
- Сохраняются проверки 12 возможных Event/NPC spots в каждой внешней зоне и безопасных городов без таких spots.
- В строке успешного PRE-FLIGHT выводятся фактические размеры мира вместо `25 / 80`.
- Добавлены регрессионные тесты, вызывающие тот же `validateWorld`, что используется при запуске браузерной игры. Тестируют нормальную карту, старую сетку 5×5, пропущенную зону, недействительную ссылку перехода и потерю Event Spot.

## Без изменений

Мир, его 225 зон, NPC, награды, вероятность T4, максимумы T2/T3/T4, таймеры, сохранения, экономика Шагов и инвентарь не менялись.

## QA

- В PR требуется CI `npm test`, синтаксис, Pre-flight validator regression и согласование версий.
- После публикации пользователь проверяет браузерный PRE-FLIGHT, старт Phaser, открытие карты, переходы между зонами и DEV World Analyzer.
- v0.2.52 сохраняется отдельным checkpoint (известен баг запуска); предыдущая пригодная точка отката — v0.2.51.
