# uGame v0.2.57 — Character Balance Registry & Admin Lab · QA prerelease

Дата: 2026-10-10. **Экспериментальная административная лаборатория**, не действующая панель публикации игрового баланса.

### Что добавлено
- Реестр всех известных **50** показателей/источников/правил: 24 производных, 5 входных, 4 столицы, 17 механик. Поиск/статусы/источник текста/текущая реализация. Честная граница «рассчитывается» и «влияет на реального персонажа».
- 📌 Закреплённая sticky-панель произвольных 24 показателей для 1–4 профилей с живым обновлением. Mobile/desktop скролл. Быстрые закрепления из реестра и строки результата.
- Быстрый фильтр по полному редактору кандидатных коэффициентов.
- Отдельный JSON snapshot (все правила, профили, реестр, трассы, результаты, предупреждения, выбранные пины) с SHA-256, валидацией, предпросмотром изменения перед импортом. Импорт **только в песочницу**, F5 отменяет эксперимент.
- [Четвёртая сверка](../work-reports/2026-10-10-character-fourth-pass-audit.md) не обнаружила новых коллизий между актуальными **утверждёнными** коэффициентами; пояснила ошибку в примере УВМ из авторского файла: 100=1%, 10 секунд→9,9 сек, а не 9 сек. Сам первоисточник не редактировался.
- [Руководство](../CHARACTER-LAB-ADMIN.md).

### Что НЕ изменено
- Сам `engine.js`, кандидатная формула `data/character-balance-candidate.json` и параметры предыдущей версии v0.2.56;
- Phaser, Character/GameState, SaveSystem, WorldGraph, Шаги и Внимание, реальные игровые ресурсы, NPC, вероятность, крафт и экспедиции.
- База 100 ХП / 10 РП остаётся демонстрационной, не принятой общегеройской нормой.

### QA
- Node: `npm test` + `node --check` всех новых модулей.
- Chromium: новая админ-лаборатория desktop 1365×768 и mobile 390×844 (реестр, pin, поиск, изменения формул, JSON roundtrip, испорченная подпись отклоняется).
- Chromium: существующая Character Lab smoke + игра Pre-flight → Phaser → 225 WorldGraph → Analyzer → Save/F5 в обоих viewport.
- Релиз допустим **только после PASS CI** на PR и main. GitHub автоматический Chromium ≠ ручной Windows QA.

### Проверка пользователем
Updater 1→11 → Project Hub → Инструменты → Character Balance Lab; закрепить несколько строк 📌, прокрутить вниз, изменить ВЫН/ХП в редакторе, экспортировать JSON, вернуть дефолт, импортировать, увидеть diff. На F5 данные эксперимента сбрасываются; игровые сохранения должны остаться прежними.
