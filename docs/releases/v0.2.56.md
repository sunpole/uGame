# uGame v0.2.56 — three-pass source audit and corrected LOV/DEF · QA prerelease

Дата 10.10.2026. Статус Character Balance Lab и UGD-0038: **discussing** (не принятый gameplay balance).

## Что изменилось

- Изолированная модель Character Balance Lab следует **последнему авторскому исправлению**: ВЫН = +0,1 ЗАЩ за единицу, ЛОВ = +1 УКЛ, **ЛОВ больше не даёт старые +0,01 ЗАЩ**. Авторский файл ugame_anton_info.txt **не менялся**.
- Трёхслойная верификация: все 394 строки / 276 непустых первоисточника классифицированы в 20 диапазонах; обсуждение №1–93 индексировано в десяти блоках; 16 систем сверены с кодом/документацией; матричные проверки 21 стартовый вариант × 65 ЗРЛ × 4 ОТВ = 5460 случаев.
- Все **24** вычисляемых показателя кандидата проверяются структурно; отсутствующие в Lab механики (ЗРП, 4 стартовых узла, активное Желание, PvP, групповые награды, офлайн-реген, полная админка) **честно обозначены как missing/partial**.
- Полный отчёт с основаниями, статусами и открытыми вопросами — [трёхслойный аудит](../work-reports/2026-10-10-character-three-pass-audit.md).
- Никаких новых UI/экспортов/пинов. Не менялись действующий игровой баланс, Phaser, шаги, классы, сохранения, реальные вознаграждения NPC и код боевых систем.

## QA / диагностика

Публиковать релиз только после успешных **npm test** (включая матрицу и ловкость/защиту), **Chromium desktop+mobile** Character Lab, **Chromium desktop+mobile** основного Pre-flight → Phaser → WorldAnalyzer → Save/F5. Для общего release workflow новая версия должна совпадать в package/version/manifest/index.

## Как проверить локально

1. Через Updater 1 обновить, затем Quick Run 11.
2. Project Hub → Инструменты → Character Balance Lab. Выбрать ЗРЛ 1/10/40/65, менять только ЛОВ: должна повышаться УКЛ, **но не должна меняться ЗАЩ**. Менять ВЫН: ЗАЩ повышается на 0,1 за единицу.
3. Проверить, что игровое состояние, прогресс и старые сейвы не изменились. Внесённые временные числовые эксперименты по-прежнему сбрасываются после обновления страницы.
4. Исходный ugame_anton_info.txt сравнить с main: неизменён. Аудит показывает известные нерешённые вопросы, он **не доказывает**, что реализация будущей игры завершена.
5. GitHub CI — не равно ручному Windows QA.
