# uGame v0.2.62 — чёткая карта мира при увеличении

**Статус:** QA-патч. Выпуск только после merge в main, зелёных CI Windows/Node/Chromium и публикации GitHub prerelease.

## Причина

В v0.2.61 экран мировой карты использовал 225 интерактивных HTML-кнопок в форме ромбов (не одну растровую картинку). Но вся сцена была помещена в CSS `transform: translate(...) scale(...)` с `will-change: transform`: браузер мог кешировать сцену как bitmap и масштабировать буквы и обводку без перерисовки. Скриншот пользователя на 225% показал мыльный текст.

## Изменение

- `src/project-hub-system.js`: новый `.world-map-camera-layer` отделяет смещение карты (`left/top`) от увеличения самой `.world-map-stage` через **нативный CSS layout `zoom`**. В Chromium это запускает повторный layout и растеризацию текста и CSS-ромбов на текущем масштабе вместо трансформации кэша.
- `src/style.css`: отключён transform и `will-change: transform` для карты. Вложенные 225 ромбов, подписи, направления, выделение и маркер игрока остались в той же системе координат и получают одинаковый масштаб. Исправлено старое мобильное правило `.project-hub-open span`, которое по ошибке скрывало **все подписи внутри окна**: теперь только `#project-hub-open span` скрывает текст кнопки открытия меню.
- `tests/browser-boot-smoke.mjs`: на настоящем Chromium desktop/mobile проверяет `zoom`, отсутствие bitmap-transform, отсутствие смещения подписей относительно ромба, сохранение геометрии при «Весь мир», «Показать меня», wheel, drag, pinch, Pre-flight, Phaser и Save/F5.
- Значения зума/границы, геометрия мира (225 зон), UI управления, сейвы, данные, экономика и игровая механика **не менялись**. Никакой новой библиотеки и SVG-слоя: текущая векторно/текстовая HTML-карта использована без переписывания 225 интерактивных узлов.

## QA

- 141 Node тестов, UI/world-map test suite.
- Реальный Chromium desktop/mobile: Web Pre-flight, Phaser, 225-зонная карта, pinch/drag/wheel/fit/focus, пиксельные геометрические согласования подписей/ромбов, Save/F5 и Character Lab.
- CI Windows PowerShell Updater — unchanged behavior.
- Отдельно от автоматических тестов: пользовательская проверка читаемости на Windows/Chrome при 100% / 175% / 225%, отсутствия дрожания при прокрутке и кликабельности зон.
