# uGame — готовые 2D-основы с 8 направлениями и возможностью смены внешности

Дата: 2026-10-12  
Тип: source research / no gameplay change  
Статус: **кандидаты для пробного импорта, не утверждённый арт-стиль**  
Проверена база uGame: main `2edab3c35662286ab3f209cf35fc50522712c5fe`, последний игровой релиз `v0.2.76` (SHA `8645b6ed4930a05a02079ce94c7ac0d86e8875b3`).

## Задача
Найти существующие 2D-шаблоны восьминаправленного персонажа, чтобы перерисовать облик и разработать смену **одежды/головных уборов/аксессуаров** с использованием спрайт-атласов в Phaser, без 3D и без новых игровых механик. Владелец работает в CorelDRAW/Photoshop; нужно минимальное число кадров и возможность легко проверить результат в браузере. Оригинальный процедурный человечек uGame должен оставаться доступен всегда.

## Кандидаты — исходный код / принцип

1. **[schlessera/semantic-sprite-skinning](https://github.com/schlessera/semantic-sprite-skinning)** — **MIT-код**, исходная разметка разных частей тела покадрово и визуальные «рецепты», экспорт спрайтов восьми направлений. README подтверждает использование ErisEsra и что сгенерированная графика НЕ покрыта MIT; в `LICENSE` это отдельно оговорено. Никакого готового `npm install` Phaser-плагина нет: подготовка разметки для новой собственной 8-направленной базы требует работы. Рассматривать как архитектурный образец/инструмент, а не автогенератор любой картинки.
2. **[paperhurts/sprite-forge](https://github.com/paperhurts/sprite-forge)** — маленький однофайловый HTML-конструктор 32×32, MIT, уже есть слои для лица/волос/одежды/аксессуаров, PNG экспорт и воспроизводимая конфигурация. Но нет полноценной восьминаправленной ходьбы; брать как пример кода смены внешности, **не как готовый 8-dir спрайт**.
3. **[LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator)** — богатый конструктор по слоям, но стандартный набор в основном **4 направления**, не 8. Код GPL-3.0, графика имеет индивидуальные лицензии/атрибуцию. **Не копировать целиком** в uGame до осознанного лицензионного решения и проверки совместимости.

## Самый маленький проверяемый эксперимент

**Не переписывать Phaser и не переносить весь генератор LPC.**

1. В отдельном `labs/` взять **один** CC0 базовый PNG-атлас Ordinary Bumblebee (32×48, 8dir), предварительно проверить содержимое скачанного архива и layout листа.
2. Дать браузерную 2D-примерочную c кнопками направлений и управлением через WASD, показывающую реальный спрайт из PNG (не нарисованную нами имитацию). Сделать только **stand + walk**.
3. Добавить один **собственный нейтральный косметический слой**, согласованный по тем же направлениям/кадрам. Слой может храниться отдельным PNG и композититься в браузере, впоследствии можно запекать atlas.
4. Сохранить первоначальный процедурный вариант uGame и прежние модели, не менять GameState, скорость, боевые параметры, экономику, сохранения или ракурс карты.
5. Node и **настоящий Chromium desktop/mobile** для PNG/Phaser и F5. Пользовательская проверка размера/ракурса на Windows отдельно.

Этот план — предложение на основе найденных источников, **не согласованное решение о финальном размере или художественном стиле**. В рамках этого исследования код игры, PNG и тесты не добавлялись.

## QA и итог
- Проверены **страницы авторов**, лицензии на них, Github README/Licenses и фактический git-repo uGame.
- **Ассеты не скачивались**, форматы содержимого архивов не проверены, browser/Windows QA этого набора **не выполнялся**.
- Коммит отчёта через отдельный docs-only PR; **релиз игры не выпускать**, предыдущие `v0.2.76`/`v0.2.75` сохранены.

Критическое различие: разрешение использовать ассет в игре не всегда разрешает публиковать исходные слои или перепродавать готовый пак отдельно. Полная «перерисовка» чужого шаблона не отменяет ограничений его лицензии — для максимальной свободы лучше CC0-источник.
