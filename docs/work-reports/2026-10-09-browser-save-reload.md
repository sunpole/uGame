# uGame — технический долг: браузерная проверка сохранения и F5

Дата: **2026-10-09**. Изменение **только QA** (без нового номера релиза).

## Исходное состояние

В v0.2.54 введён Chromium smoke-test на компьютере и мобильном экране: Pre-flight → Phaser → 225-зонная карта → DEV World Analyzer. Однако автоматический браузерный сценарий **не проверял сохранение и повторную загрузку состояния игры**, хотя после расширения 25→225 зон это критический риск.

## Исправлено

В `tests/browser-boot-smoke.mjs` поверх уже существующего сценария добавлен браузерный цикл:

1. Из отдельной пустой сессии Playwright открыть игру и пройти стартовые проверки.
2. Закрыть карту/аналитический интерфейс, через реальную форму DEV выполнить `7002` (класс «Разведчик») и `9001` (сохранить).
3. В локальном `ugame.save.v1` проверить schemaVersion 1, `player.classId=scout`, сохранённую исходную зону `loc-00013`, **220** состояний внешних локаций и состояние контейнеров.
4. Запомнить `worldSpawnState.zones['loc-00026']` как проверку дальнего кольца.
5. Перезагрузить браузер (F5 через `page.reload`), повторно дождаться зелёного Pre-flight и запуска Phaser.
6. Проверить восстановленный класс «Разведчик», тот же `world.zoneId`, все 220 Location Tier и неизменность состояния `loc-00026` (без бесплатного reroll).

Тест выполняется **на двух профилях**: desktop 1365×768 и mobile 390×844 с настоящими touch-событиями. Сессия браузера изолирована — настоящие пользовательские сохранения не используются.
