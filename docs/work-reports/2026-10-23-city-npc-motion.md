# uGame — городские модели и рывки движения, 23.10.2026

Один исполнитель. Роли: backend/визуальный runtime — причины; QA — реальные
Chromium desktop/mobile и отдельные сохранения; техписатель — доказательства.
Использованы code-work и code-verification. База: чистый main
`40c3937addc4ad730c9ea522425fa097ce2a54e3`, v0.2.78. Работа в
`codex/city-npc-motion-v0279`. Цель владельца: заменить городских NPC новыми
моделями, вернуть двух невидимых, проверить запуск/первый бой и исправить
рывки при движении и поворотах. Соседние проекты не меняются.

## Воспроизведение и причины

- Скриншот владельца воспроизведён в настоящем WebGL Phaser 4.2.1: у банкира
  и телепортера только подписи; у центрального стража старое большое тело.
- `data/knight-source/palette.json` содержит RGBA без `#`. Парсер пропускал
  первый символ как будто это `#`: например `94b5c0ff` превращалось в
  `[75,92,15,15]` вместо `[148,181,192,255]`. На вырезанном настоящем кадре
  все 1817 непрозрачных пикселей фактически имели alpha=15. Загрузка своего
  PNG этот парсер обходит, поэтому собственный герой мог выглядеть нормально.
- Центральный `loc-00013-guide` намеренно оставался без новой роли в старом
  коде. Теперь добавлен самостоятельный `guard-crossroads`, прежние 12 id
  и загруженные PNG сохранены; всего 13 графических назначений.
- CPU-проверка при реальных нажатиях направлений: `EventSpotSystem.update`
  до 433 мс за вызов; за шесть тиков 2664 запроса `getActiveMasters`, которые
  фильтровали мир и клонировали полные записи ради числа/занятых слотов.
  Повторно клонировались tier-снимки той же зоны. Перед каждым синхронным
  JSON-сохранением дополнительно клонировался целый GameState.

## Изменения

Правильный RGBA-разбор с необязательным `#`; отдельная центральная модель;
разумные новые размеры NPC по умолчанию и подписи выше всего спрайта.
Сохранённые пользовательские размеры/PNG не переписываются. При отключении
роли возвращаются прежнее тело и положение подписи.

Компактная копия occupancy содержит только count/Set идентификаторов мест;
не даёт изменить состояние мира и не копирует модули мастеров. Tier-снимок
зоны переиспользуется только внутри одного синхронного тика и обязательно
сбрасывается в finally. Следующий тик читает новые состояния/сроки. Все зоны
по-прежнему проверяются раз в секунду: баланс, RNG, сроки и схема save v1
не меняются. SaveSystem по-прежнему немедленно сериализует состояние;
убрано только предшествующее избыточное structuredClone.

## Доказательства и состояние QA

Исходные регрессии до изменений дали ожидаемые отказы: центральный страж
без роли, нет компактного запроса, горячий путь читает тяжёлые записи.
Отдельный тест цвета воспроизвёл alpha=15; отдельный тест повторных tier
чтений также упал до исправления. Целевые 17 Node-проверок затем PASS.

Первый desktop Chromium прогон: 15 непрозрачных моделей во всех пяти городах,
три действующих сервиса, восемь направлений, немутирующее синхронное save —
PASS. После оптимизации в том прогоне ненулевые event-update вызовы в среднем
9.77 мс, максимум 55.4 мс; это измерение Windows со SwiftShader, не обещание
фиксированного FPS на любом ПК. После визуального просмотра уменьшены новые
default-модели и подняты подписи; итоговый desktop/mobile прогон этих изменений — PASS.

Первый мобильный прогон показал ошибку теста: он пытался нажать скрытую
desktop-кнопку. Исправлен выбор существующей видимой action-кнопки; продукт
ради обхода проверки не менялся. Повторный desktop/mobile прогон — PASS.

Локальные сырые доказательства: `C:\Users\user\.codex\tmp\ugame-qa-20261023`;
скриншоты и JSON прогона: `artifacts/city-npc-motion/`. Эти файлы не
коммитятся. Все проверки создают новые Chromium-контексты и собственных QA
героев, не используют пользовательский профиль браузера, localStorage или
IndexedDB. Живой браузер пользователя не очищался и не менялся.

Codex Process Jobs был вызван один раз и ответил `Unsupported platform:
win32`; фоновая задача не создана. Затем проверки запущены обычными
процессами. Для Playwright используется существующая поставка Codex
1.62.1/Chromium 151 через внешний QA loader, без npm install и lockfile.
