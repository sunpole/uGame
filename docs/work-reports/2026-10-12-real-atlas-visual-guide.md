# uGame — визуальное объяснение настоящего 2D atlas (12.10.2026)

**Статус: отдельный бесплатный учебный полигон, НЕ новая версия игры.**

URL после Pages: https://sunpole.github.io/uGame/labs/real-walk-atlas.html

## Почему понадобилось
Прошлый скачиваемый урок содержал 8×4 **имитированных** кадра из статического 3×3 скриншота пользователя, два исходных слоя и третий экспортный PNG. Из-за почти одинаковых картинок и прозрачности второго слоя было сложно отличить оригинал от сборки; он **не являлся настоящей ходьбой**. Новый урок использует реальные покадровые данные, которые уже проверены в uGame 2D lab.

## Что есть
- Живая схема из 8 рядов × 11 **реальных, отличающихся по шагу кадров**, по одному направлению на ряд.
- Кнопки N/NE/E/SE/S/SW/W/NW — переключают один ряд; рядом игрок видит покадровую настоящую анимацию ходьбы.
- Одна кнопка «Скачать настоящий PNG-атлас» создаёт прозрачный лист **2816 × 2048 px**, 11 столбцов × 8 рядов, ячейка **256 × 256**. PNG можно открыть в Photoshop как единый лист; никаких 88 разных файлов не требуется.
- Легенда направлений нанесена на веб-превью, **не** на экспортный прозрачный PNG.
- Оригинал uGame сохраняется, Phaser, сохранения, XP, баланс и текущий релиз v0.2.76 не меняются.

## Источник, права и ограничения
Источник — бесплатная CC0 8-dir humanoid модель Hormelz (unarmed Knight) в формате цветовых sparse-runs JSON, опубликованная как часть Lower Lobby, по фиксированному коммиту `44fcd8f8004e61c4d66da7b3c61db534c586e166`.
- Source/credits: https://github.com/kodareef5/lowerlobby/blob/44fcd8f8004e61c4d66da7b3c61db534c586e166/CREDITS.md
- Atlas frame data: https://github.com/kodareef5/lowerlobby/tree/44fcd8f8004e61c4d66da7b3c61db534c586e166/app/public/assets/sprites/knight
- Атлас создаётся в **браузере** при нажатии кнопки; исходные art JSON остаются на CDN. Интернет обязателен для первого запуска. Никакого отдельного полного каталога слоёв доспехов у этих файлов пока нет, это цельный персонаж.
- Спецификация исходного manifest: направления слева направо/восьми рядами сверху вниз: NW, N, NE, W, E, SW, S, SE (точные dirIndex 2,3,4,1,5,0,7,6). Файл `Walk.json` содержит 11 кадров в каждом `dirs[i].frames`.

## Как проверить
1. Открыть ссылку; дождаться «Готово!», увидеть таблицу на 8 рядов и 11 столбцов.
2. Нажать «↗ NE» справа; живой персонаж должен повернуться и продолжать ходить.
3. Нажать кнопку скачивания, открыть PNG в Photoshop. Важно: картинки в PNG внутри каждой ячейки небольшие, остальное — прозрачные поля для выравнивания.
4. Для простого редактирования пока перекрашивать весь atlas через корректирующий слой Photoshop, не менять порядок/размер ячеек; для новой геометрии нужны соответствующие кадры.
5. На Windows провести ручной QA после Chromium desktop/mobile CI. CI не подменяет ручное тестирование.

**Важно:** готовая карта ходьбы не равнозначна готовой системе переодевания; слоями пока меняли только цвет, форму новых предметов эти файлы не содержат.
