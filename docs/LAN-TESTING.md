# uGame — тестирование по Wi‑Fi / LAN

Начиная с v0.0.24 локальный dev-сервер слушает все локальные сетевые интерфейсы на порту `5173`.

## Запуск

Запусти проект обычным способом через `Update-uGame.cmd` → `4` → `RUN`.

Сервер автоматически откроет локальный адрес на основном ПК и напечатает в консоли адреса локальной сети, например:

```text
uGame local: http://127.0.0.1:5173
uGame Wi-Fi / LAN:
  http://192.168.1.25:5173
```

На телефоне, планшете или другом ноутбуке, подключённом к той же домашней Wi‑Fi/LAN сети, открой один из адресов `Wi-Fi / LAN` в браузере.

## Windows Firewall

При первом запуске Windows может спросить разрешение для Node.js. Для домашней разработки достаточно разрешить доступ только для **Private networks / Частных сетей**.

Если страница на другом устройстве не открывается:

1. Проверь, что оба устройства находятся в одной локальной сети.
2. Используй адрес из строки `uGame Wi-Fi / LAN`, а не `127.0.0.1`.
3. Убедись, что dev-сервер всё ещё запущен на основном ПК.
4. Проверь, что Windows Firewall разрешил Node.js для частной сети.
5. Некоторые гостевые Wi‑Fi сети изолируют устройства друг от друга; в таком режиме LAN-тестирование работать не будет.

Сервер предназначен только для разработки в доверенной локальной сети. Для публичной публикации используется отдельный deployment на хостинг.
