# uGame v0.2.41 — первый действующий крафт

Статус: **первый игровой вертикальный срез**, пробный баланс. Отдельного города или классового ограничения пока нет.

## Сценарий
1. Получить по обычной добыче **0,4 кг камня T1** и **0,2 кг дерева T1**, нажать «Забрать» после 60-секундного Process у соответствующего Master.
2. Нажать «Мастерская» в нижней панели (на телефоне — в сенсорных кнопках).
3. В окне показаны имеющиеся материалы в рюкзаке и поясе; банк не расходуется.
4. Создать один **Простой полевой инструмент**. Камень/дерево будут списаны по единицам 0,1 кг, результат займёт слот в рюкзаке.
5. Проверить предмет в инвентаре; перезагрузка сохраняет результат через текущий SaveSystem.

## Реальные ограничения
- Один рецепт из `data/crafting-prototype.json`; статус `liveCraftingEnabled=true`.
- Результат `simple-field-tool` есть в `data/items.json`; никаких боевых, торговых или прочих эффектов пока нет.
- Если ресурсов не хватает либо нет места для результата, все контейнеры остаются неизменными.
- Защита от повтора: синхронная транзакция, блокировка повторного нажатия одной кнопки; независимое последующее изготовление при наличии материалов остаётся разрешено.
- Изменение контейнеров публикуется **один раз** после успешного создания и сохраняется стандартным игровым SaveSystem.
- Не вводились руда, шкура, профессии или специализация конкретной мастерской.

Механика предназначена для одиночного локального прототипа; безопасность от конкурентных действий разных аккаунтов потребует серверной транзакции.
