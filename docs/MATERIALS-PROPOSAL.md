# Кандидат: шесть базовых материалов uGame

Дата: 2026-10-08 · версия v0.2.31 · **не окончательное решение**

Цель — небольшой набор понятного сырья и большая глубина обработки, переделки и комбинаций.

| Материал | Текущий статус |
|---|---|
| Камень | Уже реализован с T1–T4 и хранением в кг |
| Дерево | Уже реализовано с T1–T4 и хранением в кг |
| Вода | Уже реализована с T1–T4 и хранением в кг |
| Глина | Уже реализована с T1–T4 и хранением в кг |
| Руда | Предложение, требуется утверждение |
| Шкура | Предложение, требуется утверждение |

**Утверждено:** принцип малого числа базовых ресурсов с множеством способов обработки. **Не утверждено:** именно руда/шкура как пятая и шестая категории, цены, вес/добыча, Tier-формулы, распределение по городам.

Файл `data/materials-proposal.json` существует только для планирования. Он не используется игровым `ResourceSystem`, `ItemCatalog`, `ContainerSystem` или `MasterProcessSystem`. Новые ресурсы не появятся в инвентаре и не повлияют на сохранения без отдельного согласованного патча.

Первые испытания обработки следует делать на существующих камне и дереве без новой добычи.
