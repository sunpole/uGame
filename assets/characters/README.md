Сюда загрузите **восемь исходных PNG** из папки Windows `C:\Users\user\Downloads` **без переименования и конвертации**:

| Образ | Мужской PNG | Женский PNG |
|---|---|---|
| Латный воин | `22_45_51-1.png` | `22_45_52-2.png` |
| Кожаный бретёр | `22_45_53-3.png` | `22_45_54-4.png` |
| Служитель в ткани | `22_45_55-5.png` | `22_45_56-6.png` |
| Воин духовного сана | `22_45_57-7.png` | `22_45_58-8.png` |

Каждое имя файла начинается с буквального префикса `Изображение ChatGPT 11 окт. 2026 г., ` и заканчивается суффиксом из таблицы. Код `src/hero-identity.js` использует именно эти имена.

**Куда:** ветка `feat/v0270-hero-creation`, папка `assets/characters/`, в браузере GitHub кнопка **Add file → Upload files**, затем **Commit changes** в эту же ветку. Не загружайте в `main`.

**Важно:** PNG — исходный комплект автора. Публикация версии только после проверки фактической загрузки всех 8 файлов, Pre-flight и desktop/mobile Chromium. Для ускорения загрузки позднее сделаем производные оптимизированные файлы, не затрагивая исходники.
